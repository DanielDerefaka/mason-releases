# Mason — desktop releases

Binaries for the [Mason](https://mason-puce.vercel.app) desktop app.
Download the latest from the [Releases](https://github.com/DanielDerefaka/mason-releases/releases) page,
or from [mason-puce.vercel.app/download](https://mason-puce.vercel.app/download).

macOS builds are not notarised yet, so Gatekeeper calls the app "damaged" —
Apple's wording for "not notarised". Drag Mason to Applications, then run
`xattr -cr /Applications/Mason.app` once in Terminal, and open it normally.
